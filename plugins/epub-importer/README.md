# EPUB books (importer plugin)

Copy this folder into your **Plugins** folder (Settings ▸ Plugins ▸ Open plugins folder), then Reload plugins. After that, **File ▸ Import…** (or dragging an `.epub` into the file tree) offers
**Convert**, which makes a note of the book: its chapters in order, with headings, emphasis, lists, quotes, code, tables, links and pictures. The book is left where it was. A book with copy
protection (DRM) cannot be read; the importer says so.

It is also the example of an importer plugin: see docs/plugins.md, "Importer plugins".
